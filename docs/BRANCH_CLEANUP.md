В `logic/mvp-specification` есть уникальный коммит `5cded39`, поэтому по одной ancestry его нельзя назвать включённым. Его три изменения проверены отдельно:

- Добавленный раздел «План MVP» уже присутствует в актуальном `AGENTS.md`; старые границы ответственности и `src/style.css` не возвращаем.
- Полезная ссылка на MVP сохранена в итоговом README. Старый README не переносим поверх описания платформы, лаборатории и школы точения.

Новых продуктовых требований из старой ветки не добавляли. Уникальных неперенесённых возможностей в снимке веток не обнаружено. Категория «содержит уникальные изменения» применима к истории `5cded39`, но не означает отсутствующую функцию. Решение автора нужно для окончательного закрытия старой документальной ветки и согласования подробностей самого MVP; архив позволяет сохранить исходное предложение независимо от этого решения.

## Условия будущей очистки

1. PR должен быть принят в main полноценным merge (squash/rebase потеряет проверяемую ancestry исходных веток).
2. Снова получить origin и проверить точные вершины: новые коммиты после снимка требуют повторной оценки и нового уникального архивного тега.
3. Проверить `git merge-base --is-ancestor <ветка> origin/main` для строк «после PR». Для эквивалентного патча отдельно повторить `git cherry` и сравнить diff.
4. Проверить статус каждой занятой worktree и получить решение её владельца; существование архива не разрешает удалять незакоммиченную работу. Не применять force delete.
5. Очистку локальных и удалённых веток выполнять только по отдельному указанию пользователя. Не трогать main, origin/HEAD и активную интеграцию.
