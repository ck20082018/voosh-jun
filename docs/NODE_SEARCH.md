# Поиск и быстрое создание нод

Пакеты MVP: M5 (авторский редактор) / M6 (надёжность и визуальная приёмка). Задача явно запрошена владельцем; объём ограничен поиском существующих типов. Перенос токарных уроков в граф и изменение 3D не выполнялись.

Ветка `logic/node-search` создана от актуальной `origin/main` (`db942e2`) в чистой основной папке, без новой worktree. Предыдущая интеграция остаётся отдельным PR #18; её ветку и Docker-контейнер эта задача не меняет. Код поиска для проверки — `d35c06f`; далее в PR добавлен только этот отчёт.

## Данные и поведение

Реестр `registry` в `level.ts` остаётся источником типов. В нём добавлены категории и синонимы; описание используется существующее. Поиск нормализует регистр, «ё» и пробелы; все слова должны встретиться в названии/описании/синонимах/ID. Точное название выше частичных совпадений. При пустой строке сначала показываются до пяти недавних типов, затем категории без повторения типов.

Двойной щелчок ЛКМ допускается только на фоне графа и свободном фоне рамки. Ноды, заголовок группы, порты, связи, resize-маркеры, поля, кнопки, панели и миникарта исключены. Отключено только масштабирование двойным щелчком; колесо, ЛКМ-перемещение, ПКМ-рамка и библиотека сохранены. Кнопка «Найти ноду» использует центр видимой части графа.

Состояния окна: ввод/выбор; нет результатов с очисткой; ошибка ограничения с переходом к существующей ноде; успешное создание с закрытием. Ввод получает фокус, combobox/listbox имеют доступные названия и активный результат; стрелки прокручивают выбранную строку в видимую часть. Клавиши окна не доходят до редактора, Escape и внешний клик закрывают его. Размещение ограничено рабочей областью и видимым окном браузера.

Используется общая `addEditorNode`: поиск свободного места, запрет второй карты и лимит 100 нод применяются также к прежним способам добавления. На успехе выделяется новая нода, открываются свойства, масштаб сохраняется. Координата вызова преобразуется через `screenToFlowPosition`; сохранённая позиция абсолютная, членство в группе добавляется в той же транзакции. Только адаптер React Flow вычитает позицию рамки. Повторные события одного открытого поиска не создают вторую ноду.

История расширена redo: одна отмена удаляет ноду вместе с членством в группе, повтор восстанавливает тот же снимок. Кнопки «Отменить» / «Повторить», Cmd/Ctrl+Z и Cmd/Ctrl+Shift+Z работают вне полей. Открытие, запрос и выделение результата не редактируют уровень. Предпочтения `factory-editor-recent-node-types-v1` отделены от JSON v4; ошибки localStorage игнорируются только для этих необязательных предпочтений. Формат уровней и ID портов не изменены.
